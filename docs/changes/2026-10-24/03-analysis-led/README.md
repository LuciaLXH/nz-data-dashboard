# 第三步：从指标介绍回到数据分析

## 这次为什么重做

项目作者指出上一版标题像通用模板，分析减少，页面层级平，普通读者难以获得有用信息。
原因不是解释还不够多，而是页面先摆指标，再用长篇说明补救；没有让具体发现成为阅读主线。
本轮保留双语与准确口径，重做内容组织。

## 改了什么

- 删除 “Three numbers, three different questions / 三个数字，回答三个不同的问题”。
- 第一段分析从具体差异开始：霍克斯湾与奥克兰报告的人均供水约相差 2.3 倍，
  两地同期人口年均增速分别约 0.2% 与 1.2%。用六地区关系图展示完整对照。
  比值来自未四舍五入的人均供水结果，没有新抓数据；不据此声称居民浪费、效率差或因果关系。
- 第二段把水损率与资料范围一起展示：奥克兰约 19.6%、怀卡托约 19.9%，
  参与网络却分别覆盖约 100% 和 33% 的报告供水。图中同时展示六地区，避免只挑两个例子。
  100% 是保留一位小数后的显示，原值约为 99.967%。
- 可以切换是否包含私人地块内损失，直接看到选中的网络群组改变。
  例如南地在默认范围无可比值，但在“包含”范围有记录；不能把切换当作同一批网络加减水损。
- 关系图中的点、覆盖图的地区按钮与下方地区选择联动，键盘也能操作。
- 河流先展示附观测日期的历史位置图，完整结果表仍可展开。
- 主要分析用大图、旁注与独立色块区分层级；地区查询作为辅助，气候背景收进可展开区域。
  手机上的关系图在图内横向滚动，不把整页撑宽。

## 普通读者能得到什么

能据此检查两种常见说法：“人均供水更高就是居民用水更多”，以及“水损率接近就能直接排名”。
页面展示反例和资料边界，让人知道下一步应问哪些问题。
它仍不能回答某家庭今天是否停水或限水。这个功能需要另外接入供水通知、水源与需求状态，
不能把已有资料包装成实时生活服务。
