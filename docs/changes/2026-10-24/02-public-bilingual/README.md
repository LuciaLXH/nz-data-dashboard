这次改变的是页面要为谁服务、先回答什么问题。新增公众阅读版，同时保留英文详细分析页。
没有修改指标公式，也没有重新抓取生产数据。

## 之前与之后

之前：从供水、漏损和河流三个分析入口开始，读者要先理解指标术语。
之后：从日常关切和地区选择开始；每个数字紧接解释、年份与覆盖范围。
补充厄尔尼诺背景时间线、家庭与乡村场景，以及查询当前官方信息的方向。

中文与英文公众版共用数据，语言切换保留所选地区。站点原名、机构缩写和来源文件保持原样。
详细地图、取水许可和完整技术表格目前仍在英文分析页，入口如实标注语言。
